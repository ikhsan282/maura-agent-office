# Maura Agent Office

3D visualization dashboard untuk monitoring Maura multi-agent system.

## Features

- Real-time 3D office visualization dengan Three.js
- Agent metrics dan status monitoring
- Interactive controls (pan, rotate, zoom)
- Agent details dialog
- Filter by status (working, idle, recent)

## Stack

- Frontend: Vanilla JS + Three.js
- Backend: Python standard library (`http.server` + SQLite read-only)
- Styling: Custom responsive CSS

## Run

```bash
python3 server.py
```

Buka http://localhost:3001
